# 02-评测数据集

用 NestJS 独立应用演示评测前的数据准备，不启动 HTTP 服务，不调用模型，不计算 Agent 得分。

## 运行

使用 Node.js 22.20 或以上版本，在本目录执行：

```bash
npm install
npm run demo
```

不需要 API Key、环境变量文件、Docker 或数据库。

## 查看什么

- `data/dataset.json` 保存 7 条样本，包括用户输入、身份上下文和各轮检查要求。
- `data/fixtures.json` 保存合成订单与退款规则，作为每次运行的固定业务资料。
- `src/main.ts` 是演示入口，先列出样本，再分别打印 Agent 输入和评分参考。
- `src/dataset.service.ts` 的 `prepare()` 为每次运行创建独立的数据副本、消息和记忆；`getReference()` 单独返回评分参考。

演示最后直接把第一份副本的金额从 3500 改成 1，再准备第二次运行。第二份副本仍是 3500，消息和记忆均为空。这是程序验证环境隔离的实验，不是真实 Agent 操作。

`inputs.turns` 是按顺序发送的用户消息。后续执行多轮样本时，应保留同一次运行的实际模型回答和工具结果，再发送下一轮用户消息，不要用参考答案填充对话。

`environment` 由应用保存，订单与规则后续供工具读取。它不是要全量交给模型的 Prompt。`referenceOutputs` 只供评分程序使用。

结构检查验证字段、样本 ID、轮次数量和资料引用；参考事实与业务要求仍需人工核对。当前的内存副本只演示隔离原则，接入数据库或持久化记忆时还需独立测试空间及清理机制。

## 验证

```bash
npm run check
npm test
```

测试覆盖参考结果分离、副本隔离、格式错误，以及样例金额和审核边界的一致性。
